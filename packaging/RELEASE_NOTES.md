# VibeDxf v0.1.1

Spline support, independent measurement strategies, and a corrected arc selection highlight.

- Render and select control-point SPLINE entities, including positive rational weights and periodic curves. Each spline remains one selectable element.
- Measure spline-to-line, spline-to-arc, and spline-to-spline distances. Spline measurements show ≈ and use an approximation tolerance of 0.0001 drawing units per spline.
- Choose Center or Closest independently for the orange and blue selections using the bottom-right toggles. Changes immediately update the connector, distance, ΔX, and ΔY without reselection. These strategies affect only standalone circles and arcs.
- Fix arc highlights bowing to the opposite side of the selected arc.
- Add offline geometry and GPU rendering regression checks, an HTML visual test report, and clean failure reporting for console checks.
- Verified the C25F reference drawing loads all 4,284 entities, including 315 splines, with none skipped.

## Requirements

Windows 10 or later, x64. Install the **.NET 10 Desktop Runtime x64** separately if needed:
https://dotnet.microsoft.com/download/dotnet/10.0

The runtime is not included and the installer does not download or install it. The .NET SDK is not needed. Windows includes several .NET versions in different ways; a different .NET major version or the ASP.NET runtime alone does not meet this requirement.

The installer is unsigned; Windows may display an unknown-publisher warning.

Supported geometry: ASCII DXF LINE, ARC, CIRCLE, 2D polylines including bulges, and degree 1–16 control-point splines with positive weights. Fit-point-only splines, nonplanar splines, nonpositive weights, malformed spline data, blocks/INSERT, text, dimensions, hatches, ellipses, binary DXF, and general 3D/OCS geometry remain unsupported.

The test report is generated by the console checks at artifacts/test-report/index.html. Visual Studio Test Explorer integration is not included in this release.
